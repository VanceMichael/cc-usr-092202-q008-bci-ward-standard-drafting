# 脑机病房标准编制

支持脑机接口病房团体标准的提案、征求意见、试点和表决发布。

## 业务事实

- 广东已有多家医疗机构设立脑机接口相关病房或中心
- 联合体计划定期汇总医院科室真实需求
- 现阶段产品以非侵入式应用为主且仍需临床验证

## 协作角色

- 临床科室
- 伦理委员会
- 科研团队
- 设备企业
- 受试者管理人员

## 目录说明

- `contracts/domain.schema.json` 定义共享资料的字段与基本约束。
- `fixtures/context.json` 提供不含真实个人信息的公开样例。
- `src/records.py` 提供资料读取与基础校验逻辑，便于后续服务统一接入。
- `src/drafting/` 是协同编制平台：章节、术语、规范性引用、提案、意见、反对意见、试点证据、会议表决与发布留档的全过程记录与门禁。

## 协同编制流程

1. **并行草案**：同一条款可建多份草案；未公开草案仅作者及指定角色可见，进入征求意见后全员可见。
2. **征求意见与逐条处理**：意见须逐条给出采纳/部分采纳/不采纳及理由，反对意见须了结后方可送审。
3. **试点验证**：标记需试点的条款必须有验证通过的脱敏证据才能送审。
4. **会议表决**：送审稿只能来自全体出席者完成利益冲突声明且编制组出席达到法定人数的会议，赞成票须达有效票三分之二。
5. **引用撤回**：规范性引用撤回时自动定位受影响条款并阻断送审，处理结果留档后解除。
6. **发布留档**：每条正式要求可溯源提出者、试点证据、异议处理与生效日期，新版本发布后旧版本自动标记为被替代。

## 本地检查

运行项目自带测试可确认样例能够读取，领域标识、版本、参与者和记录结构完整。样例中不包含账号、密钥或连接凭据。
