# 脑机病房标准编制

支持脑机接口病房团体标准的提案、征求意见、试点和表决发布。

## 业务事实

- 广东已有多家医疗机构设立脑机接口相关病房或中心
- 联合体计划定期汇总医院科室真实需求
- 现阶段产品以非侵入式应用为主且仍需临床验证

## 协作角色

- 临床科室
- 伦理委员会
- 科研团队
- 设备企业
- 受试者管理人员
- 秘书处(平台内置,负责送审、发布与引用撤回等操作)

## 目录说明

- `contracts/domain.schema.json` 定义共享资料的字段与基本约束。
- `contracts/observations.schema.json` 定义脱敏试点观察样例的结构。
- `fixtures/context.json` 提供不含真实个人信息的公开样例。
- `fixtures/pilot_observations.json` 提供脱敏试点观察样例(仅病区级汇总指标)。
- `src/records.py` 读取并校验共享领域资料。
- `src/drafting.py` 领域模型:条款、术语、规范性引用、提案、意见、证据、会议、表决与留档记录。
- `src/platform.py` 协同编制平台,执行下述流程规则。
- `src/observations.py` 读取脱敏观察样例,未脱敏记录直接拒绝。

## 流程规则

- 同一条款允许并行草案;同一时刻仅一份生效要求,新发布自动替代旧版并保留留档。
- 意见逐条处理,必须记录采纳/部分采纳/不采纳及理由;未处理完毕不得送审。
- 试点证据必须脱敏;标注需要试点验证的条款无证据不得送审。
- 送审稿只能由达到法定人数且利益冲突声明齐全的会议经表决(默认 3/4 同意)通过后形成;表决未通过草案退回。
- 规范性引用撤回时,平台精确列出受影响的未发布草案与已发布要求并打标,新草案不得再引用。
- 未公开草案仅作者本人、作者所在角色与秘书处可见,进入征求意见后向全体注册角色开放。
- 每条已发布要求留档提出者、试点证据、异议处理、表决会议与生效日期。

## 本地检查

运行 `python -m unittest discover -s tests` 可确认样例能够读取,领域标识、版本、参与者和记录结构完整,并覆盖上述流程规则。样例中不包含账号、密钥或连接凭据。
